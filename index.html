Javascript

JavaScript is a versatile programming language used to build interactive, dynamic websites and web applications. It works in browsers and on servers, enabling features like user interaction, animations, and real-time updates.

React

React is a popular JavaScript library for building dynamic and responsive user interfaces. It uses a component-based approach, making applications easier to develop, maintain, and scale, and is widely used for modern web applications.

Node.js

Node.js is a powerful JavaScript runtime built on Chrome’s V8 engine that enables developers to run JavaScript on the server. It is widely used for building fast, scalable, and real-time backend applications such as APIs, web servers, and microservices.

Mongodb

MongoDB is a popular NoSQL, document-oriented database that stores data in flexible JSON-like format. It is designed for scalability, high performance, and easy integration with modern applications, especially those built with JavaScript and Node.js.
